## About Me

I am a Full-Stack Developer and Senior Frontend Engineer specializing in building and scaling high-performance, real-time web applications and SaaS products. I have extensive experience working with remote-first teams across the US, UK, and Africa, taking complex platforms from concept to production.

My technical focus centers around React, Next.js, Svelte, and Node.js ecosystems, with strong emphasis on real-time multiplayer architectures, modern state management, and optimized UI design.

## Experience & Impact

Over the course of my career, I have architected and delivered production-grade web applications spanning real-time multiplayer platforms, event management ecosystems, and custom e-commerce applications. My technical leadership includes designing low-latency multiplayer web backends with Node.js and Firebase, as well as engineering robust cloud-backed architectures leveraging AWS services (S3, EC2, RDS, API Gateway, Amplify, Cognito), PostgreSQL, Prisma, Upstash Redis, and serverless runtimes.

In addition to full-stack feature delivery, I focus heavily on frontend performance and developer experience. I successfully led a toolchain migration to Vite that cut deployment times by 80%, designed complex dynamic form builders, and implemented modern SSR, secure cookie authentication, and API integrations across high-visibility platforms.
